# Phantom Nexus

**MUGEN ライクな 2D 格闘ゲーム基盤**。キャラクター・ステージ・技・当たり判定・AI を **外部データ（JSON）** として追加・編集できる、拡張性の高い 2D 格闘ゲームエンジンを目指す。

- 技術スタック：**Java / LibGDX / Gradle**、データ形式 **JSON**（LibGDX 組込み）
- 対象：**Windows PC**（将来 Linux / macOS）
- 開発運用：実装は **Claude Code**、レビューは **Codex（GitHub App）＋ CodeRabbit ＋ Claude セルフレビュー（CI / fresh context）** の 3 系統
- 開発指針・ルールは [CLAUDE.md](CLAUDE.md)、Codex 向け指示は [AGENTS.md](AGENTS.md) を参照

---

## ビルドと実行

```sh
./gradlew build      # 完了基準（コンパイル + テスト）
./gradlew test       # テストのみ
./gradlew run        # デスクトップ（LWJGL3）で起動
```

JDK は Gradle toolchain で Java 17 を自動取得する（要ネットワーク）。Windows は `gradlew.bat` でも可。

## 操作方法

| 操作 | P1 | P2（人間時） |
|---|---|---|
| 移動 | A / D | ← / → |
| ジャンプ | W | ↑ |
| しゃがみ | S | ↓ |
| 弱攻撃（light） | F | Numpad 1 |
| 中攻撃（medium） | G | Numpad 2 |
| 強攻撃（heavy） | H | Numpad 3 |
| 投げ（throw） | T | Numpad 0 |
| 必殺技（波動拳） | ↓→ + 攻撃（236+任意攻撃ボタン） | 同左 |

- **空中攻撃**：ジャンプ中に攻撃ボタン（弱/中/強）を押すと空中攻撃（飛び込み）。下段は **しゃがみ中に攻撃**（立ちガード不可）。
- **ガード**：相手と逆方向（後退方向）を保持すると立ちガード（chip のみ・のけぞりなし）。しゃがみ後退で**しゃがみガード**（下段を防ぐ）、**ジャンプ中に後退保持で空中ガード**（Task 59・飛び道具や中段/上段を滞空中に chip で凌ぐ）。連続ガードでガードゲージが尽きると**ガードクラッシュ**（ガード不能の隙）。
- **投げ**：地上・立ちで投げボタンを押すと近接の相手を掴む **ガード不能の投げ**。立ち/しゃがみどちらのガードでも防げない（ジャンプで回避可）。ガード偏重の相手を崩す択。**掴まれる瞬間に投げボタンを返すと「投げ抜け」**でノーダメージに（Task 36）。
- **F1**：デバッグ当たり判定表示の ON/OFF（push=青 / hurt=緑 / hit=赤）
- **F2**：P2 の AI ⇄ 人間 切替（既定は P2=AI）
- 勝敗：制限時間内に相手の HP を 0 にすれば KO。時間切れは HP 残量が多い側の勝ち。

## 実装済み機能（タスク 1〜40 ＋ 追加機能）

- **基盤**：LibGDX/LWJGL3 ウィンドウ・固定仮想解像度（1280×720）・60fps 固定ステップ
- **操作/移動**：キーボード入力抽象・左右移動・ジャンプ（重力/接地）・向き自動追従・しゃがみ（DOWN 押しで低姿勢）・しゃがみ移動（DOWN+左右で通常速度の半分でクロール）
- **アニメーション**：idle / walk / jump / jump_attack / attack / throw / hitstun / guard / crouch / crouch_attack / crouch_walk / crouch_guard の状態機械（tick ベース）
- **スプライト描画（Task 34）**：キャラ JSON の `sprite`（スプライトシート PNG ＋ フレーム寸法 ＋ 状態→行マップ）を `SpriteLibrary` が読み込み、アニメ状態（→行）・フレーム（→列）に同期した `TextureRegion` を向き反転つきで描画。被弾は赤ティント・しゃがみは高さ圧縮・ガード/攻撃 strike オーバーレイは矩形と共通。`sprite` 未指定キャラは従来のプレースホルダ矩形へフォールバック（後方互換）
- **2P パレットスワップ（Task 62）**：**ミラーマッチ（P1 と P2 が同じキャラ）のときだけ** P2 の本体を乗算ティントで色変えし、左右どちらが自分かを一目で識別できるようにする（格闘ゲーム定番の 2P カラー）。別キャラ対戦では適用せず従来どおりの見た目（既存の見え方に回帰しない）。純粋な描画演出で戦闘結果には影響しない・乱数なし
- **戦闘**：HP ゲージ・通常攻撃（startup/active/recovery）・しゃがみ攻撃（低姿勢を維持したまま攻撃・DOWN 離しで攻撃終了と同フレームに立ち上がり）・当たり判定（hit/hurt/push）・ダメージ/のけぞり/knockback・ラウンド勝敗（KO/タイムアップ）
- **ダメージ数値ポップアップ（追加機能）**：被弾 / ガード時に「実際に減った HP 量」を命中位置から数字で浮かび上がらせる（通常ヒット=黄 / ガード chip=青）。上昇＋終盤フェードで消える純粋な演出（戦闘結果には影響しない）。chip 量が一目で読め、手応えも増す
- **ヒットスパーク（Task 38）**：打撃 / 飛び道具 / 投げの命中・ガード・投げ抜けの接触点に放射状の火花を出す手応え演出（通常ヒット=黄/白・ガード=青）。拡大＋フェードで約 0.2 秒で消える純粋な演出（戦闘結果には影響しない）。`DamagePopup` と同じ Battle POJO ＋ Core 所有リスト ＋ Renderer 描画パターン
- **コンボカウンター（Task 39）**：被弾側が hitstun 中にさらに被弾したら連続ヒットとして数え、相手の頭上に `N HITS!` を表示（2 ヒット以上で出る）。回復（hitstun 切れ）でリセット。**真のコンボ（hitstun 連鎖）のみ数える**ため、復帰が hitstun より遅い技の追撃（＝リセット）は加算されない。乱数なしで決定的（入力リプレイと両立）
- **下段判定（Task 31）**：しゃがみ攻撃は脚部の低位 hitbox を出す**下段技**。立っている相手の脚に当たり、**立ちガードでは防げず通常ヒット**・しゃがみガードでのみ chip。中段（立ち攻撃）との読み合いが生まれる
- **投げ技（Task 35）**：地上・立ちで投げボタン（P1=T / P2=Numpad0）を押すと近接の相手を掴む**ガード不能の投げ**。立ち/しゃがみどちらのガードも貫通しフルダメージ＋長い拘束を与える（打撃＝ガードで凌げる／投げ＝ガード貫通の二択）。空中の相手は掴めない（ジャンプで回避可）。キャラ JSON の任意 `throwMove` でデータ化（未指定キャラは投げ無し＝後方互換）
- **投げ抜け（Task 36）**：掴まれる直前〜直後に**こちらも投げボタンを押すと投げ抜け（throw tech）**が成立し、掴みがノーダメージで相互に弾かれる（短い硬直のみ）。ガード不能の投げに対する唯一の対抗策で、これで「打撃＝ガード／投げ＝投げ抜け／空中＝ジャンプ」の択が揃う。同じ投げボタンで出せる（新キー無し）
- **打撃必殺技／無敵リバーサル（Task 53）**：飛び道具でない**打撃の必殺技**（`projectile=false`）に対応し、技の発生に**無敵フレーム**（JSON の任意 `invincibleFrames`）を付けると相手の攻撃を抜いて切り返す**昇龍拳タイプの無敵対空**になる。無敵中は打撃も飛び道具も食らわず（状態ラベルに `[INV]` 表示）、無敵技自身の攻撃は刺さる＝抜けつつ反撃。長い recovery でリスクを取る読み合い。例：Aoi が `fireball`（236・飛び道具）＋ `rising_dragon`（溜め 4→6+攻撃・無敵対空）の 2 系統を持つ。`invincibleFrames` をデータ化したので技ごとに無敵長を設定可・乱数なしで決定的
- **空中攻撃（Task 32）**：ジャンプ（滞空）中に攻撃ボタンで通常技を発動（飛び込み）。降下に伴い hitbox も下がり地上の相手に届く。中段扱い・着地後も技の残りフレームは進行
- **ガード高さ属性（Task 33）**：技ごとに `guardHeight`（`overhead`/`mid`/`low`）を JSON でデータ化。**上段（overhead）は立ちガードのみ可・しゃがみガード貫通**で、下段（しゃがみガード必須・Task 31）と対の読み合いになる。中段（既定）は両ガード可。未指定の旧 JSON は `mid` 扱い（後方互換）。例：Aoi の強攻撃 `heavy_slam` を overhead 化
- **ガード（Task 27 / 30）**：後退方向保持で立ちガード・chip ダメージ（通常の 10%、最低 1）・のけぞりなし・半透明ブルーオーバーレイ。しゃがみ中の後退方向保持で**しゃがみガード**（低姿勢ガード・Task 30）
- **ダウン（knockdown・Task 60）**：技 JSON の任意 `knockdown: true` を**非ガードで**食らうと、通常のけぞりではなく**ダウン**（一定フレーム行動不能・**ダウン中は被弾無敵＝起き攻め/OTG なし**）に陥り、約 1 秒後に自動で起き上がる。データ駆動で技にフラグを足すだけで増やせる（例：Aoi の `heavy_slam`）。乱数なしで決定的
- **受け身（ukemi・Task 66）**：ダウン**直後の受付窓**（12 フレーム）内に行動入力（攻撃／ジャンプ／投げ）をすると、残りダウンを短縮して**早く起き上がる**（フル 60 → 20 フレーム）。起き攻めへの対抗択。ただし早く起きる＝**ダウン中無敵も早く切れる**ためノーリスクではない。専用キーは不要（行動ボタンで成立）。グローバル機構（JSON 不要）・乱数なしで決定的。状態ラベルに `knockdown(ukemi)` を表示
- **複数ラウンド制（Task 26）**：先取 2 ラウンド（ベスト・オブ 3）・インターバルバナー・勝利ドット（HP バー横）・マッチ結果表示（勝者 + スコア）
- **ラウンド開始イントロ（Task 42）**：各ラウンド開始時に "ROUND N" → "FIGHT!" 演出を再生し、その間は操作・判定・タイマーを停止（格闘ゲーム定番の試合開始シーケンス）。撮影時は既定スキップ・`-x intro=true` で演出を撮影可能
- **ガードゲージ／ガードクラッシュ（Task 43）**：ガード成立のたびにガードゲージ（HP バー直下に表示）が攻撃力に応じて減り、尽きると "GUARD BREAK!"＝一定フレームのガード不能・行動不能の隙が生じてフル確定反撃を許す。非ガード時は徐々に回復。「固める」択への崩しの読み合いを成立させる
- **必殺技ゲージ／EX 必殺技（Task 44 / 54）**：攻撃を当てる/受ける/ガードで必殺技ゲージ（画面下端に表示）が貯まり、満タン（金色）で必殺技を撃つと消費して **EX 版**になる。**飛び道具**はダメージ 1.6 倍・大型の金色弾、**打撃必殺技（Task 54）**はダメージ 1.6 倍＋金色 strike＋`[EX]` 表示（例：Aoi の無敵対空 `rising_dragon` 110→**176** の EX 無敵対空）。ガードゲージ（防御）と対になる攻撃リソース。乱数なしで決定的（撮影は `-x p1meter=` でオーバーライド可）
- **チェーンコンボ（Task 45）**：命中した通常技の硬直を待たず、より強いボタンの通常技へキャンセルして繋げる（弱→中→強の一方向ガトリング）。単発では届かない連続ヒットが成立し、コンボカウンター（Task 39）が実用化する（例：弱→中→強で `3 HITS!`・50+80+130=260 ダメージ）。乱数なしで決定的
- **コンボダメージ補正（Task 46）**：コンボが伸びるほど後続ヒットの与ダメージを段階的に減衰（2 ヒット目から 10%ずつ・下限 30%）。長いコンボのリターンを鈍らせて無限・即死コンボを抑える。ダメージ数値ポップアップが補正後の値を表示（例：弱→中→強チェーンが 50/72/104＝合計 226、補正前 260）
- **特殊キャンセル（Task 47）**：命中した通常技を必殺技（飛び道具等）でキャンセルして繋ぐ（チェーンコンボの必殺技版）。通常技 → 必殺技でコンボを締め・伸ばせる（例：弱P→波動拳で `2 HITS!`・50+108＝合計 158）。EX 必殺技でのキャンセルも可。乱数なしで決定的
- **ダッシュ（Task 49）**：同じ方向を素早く二度押しすると、通常歩行より速い短いダッシュ（前ステップ／バックステップ）に入る。歩き・ジャンプに次ぐ第3の移動手段で、間合いの素早い詰め／離脱の択を足す（攻撃・必殺技・投げ・ジャンプ・しゃがみ・被弾でキャンセル可）。乱数なしで決定的
- **空中投げ（Task 70）**：`airThrowMove` を持つキャラは、**滞空中に投げボタン**で空中の相手専用のガード不能掴みを発動する。地上投げが地上の相手のみ掴めるのに対し空中投げは滞空中の相手のみ掴める（投げは掴む側と掴まれる側の接地状態が一致したときのみ成立＝地上投げはジャンプで、空中投げは着地で回避可）。空対空の択。JSON の任意 `airThrowMove`（既定なし）でデータ化＝持つキャラだけが使える（例：Rai の `sky_grab`）。乱数なしで決定的（持たないキャラは従来どおり空中投げなし＝後方互換）
- **空中ダッシュ（Task 69）**：`airDashes` を持つキャラは、**滞空中に方向二度押し**で水平バーストダッシュ（前/後・重力で弧を描く）ができる（接地で回数回復）。JSON の任意 `airDashes`（既定 0）でデータ化＝持つキャラだけが使える（例：Rai の `airDashes:1`＝二段ジャンプと合わせて高機動ラッシュ型）。地上ダッシュ（Task 49）の二度押しを滞空でも許可した実装で、ダッシュ攻撃・空中ガード・二段ジャンプと両立。乱数なしで決定的（持たないキャラは従来どおり空中ダッシュなし＝後方互換）
- **二段ジャンプ（Task 68）**：`airJumps` を持つキャラは、地上ジャンプの後に**空中でもう一度ジャンプ**できる（下降中でも跳ね上がる・接地で回数回復）。JSON の任意 `airJumps`（既定 0）でデータ化＝持つキャラだけが使える（例：Rai の `airJumps:1`）。空中攻撃・空中ガードと両立。乱数なしで決定的（持たないキャラは従来どおり地上ジャンプのみ＝後方互換）
- **ダッシュ攻撃（Task 65）**：ダッシュ中に攻撃ボタンを押すと、`dashAttack` を持つキャラは通常技でなく**突進打撃**が出る。ダッシュの勢いを引き継いで前方へ踏み込みながら攻撃する接近の起点（突進初速はフレームごとに減衰）。JSON の任意 `dashAttack` でデータ化＝持つキャラだけが使える（例：Rai の `dash_shoulder` dmg80）。持たないキャラはダッシュ中の攻撃が従来どおり通常技になる（後方互換）。乱数なしで決定的
- **データ駆動**：キャラ/ステージを外部 JSON から読込（`Shared/Schema` の単一の真実 + バリデーション）。キャラは複数（`fighter001` Aoi / `fighter002` Akane / `fighter003` Tetsu / `fighter004` Rai / `fighter005` Sora / `fighter006` Iwao＝**飛び道具を持たない純グラップラー**：最高 HP1200・最遅・短リーチ高火力の通常技・最大火力の投げ `back_breaker`（dmg175）＋無敵リバーサル `rising_hammer` / `fighter007` Kaede＝**飛び道具＋ knockdown heavy・無敵リバーサルを持たない footsies 型**：中リーチの poke・強攻撃 `roundhouse` が `knockdown:true` でダウンを奪う・飛び道具 `wind_shot`）・ステージは複数（`stage001` Twilight Arena / `stage002` Verdant Glade）を JSON だけで追加・差し替え可能（Task 22 / 40 / 41 / 48 / 52 / 58 / 61。撮影は `-x p1char=<id>` / `-x p2char=<id>` / `-x stage=<id>` でオーバーライド）。新キャラはコード変更なしでチェーンコンボ・特殊キャンセル・必殺技ゲージ・**ダウン（Task 60・技に `knockdown:true` を足すだけ）**等の既存機構をそのまま使える（Iwao は飛び道具を持たなくても、データ駆動 AI の無敵対空（Task 55）が `rising_hammer` を**無改修で**対空に使う）
- **複数技（Task 24）**：`normalMoves[]`（弱/中/強 3 ボタン）・`specialMoves[]`（複数コマンド技）を JSON で定義。P1: F/G/H、P2: Numpad 1/2/3
- **コマンド技/必殺技**：入力履歴＋コマンド検出（波動拳 236+A 等）・飛び道具の必殺技
- **AI（Task 21 / 37 / 50 / 51 / 55 / 56 / 57 / 63 / 64）**：接近して間合いで攻撃する簡易 AI（P2 既定）に、**読み合い反応**を追加。相手の打撃に合わせて**ガード**（chip で凌ぐ）し、相手が**ガード中**なら打撃では崩せないので**投げ**で崩す。**Task 51** で**投げ抜け反応**を追加：相手が**投げ中**で近接なら投げ抜け窓をアームして掴みを**抜ける**（ノーダメージ）＝「打撃＝ガード／ガード＝投げ／投げ＝投げ抜け」の三すくみが完成（ただし AI の技の硬直を投げで狩る崩しは残る）。さらに **Task 50** で**ダッシュ接近**：中心間が遠い（> 260px）ときは歩きでなく**ダッシュ**（二度押し前ステップ）で素早く間合いを詰める。**Task 55** で**無敵対空**を追加：無敵リバーサル（打撃必殺技）を持つキャラの AI は、飛び込んでくる相手（空中＋下降中）をその無敵技で迎撃する（AI が初めて必殺技を使う・`self.startSpecial` を直接呼ぶ）。データ駆動で、キャラ JSON に無敵打撃技があれば AI もそれで対空する（fighter002 Akane の `rising_talon`）。**Task 56** で**難易度**（EASY/NORMAL/HARD）を追加：実装済みの反応群を段階的に解放する（EASY=接近＋攻撃のみ／NORMAL=＋ガード・投げ崩し／HARD=＋投げ抜け・ダッシュ接近・無敵対空・飛び込み＝全反応）。既定は HARD（従来挙動）。**Task 57** で**飛び込み（ジャンプ攻撃）**を追加：中距離（150〜260px）から**前方ジャンプで踏み切り**、空中で相手へドリフトして下降中に**空中攻撃**（Task 32）を重ねる（HARD のみ・クールダウン明けに歩き接近と交互＝一辺倒にならない）。無敵対空（Task 55）を持つ相手には落とされる＝攻防が成立。**Task 63** で**下段読みのしゃがみガード**を追加：相手の打撃が**下段**（しゃがみ攻撃 or `guardHeight:low` 技）なら立ちガードでなく**しゃがみガード**で対応する（HARD のみ）。NORMAL は従来どおり立ちガード一辺倒で下段に貫通されて被弾する＝難易度差（例：Tetsu の `low_sweep` に HARD は `crouch_guard`・chip 12／NORMAL は `hitstun`・フル 120）。判断は相手の観測状態と距離のみで**乱数なし＝決定的**（入力リプレイと両立）。**Task 64** で**飛び道具牽制（zoner）**を追加：**飛び道具を持つキャラ**の AI は遠距離（中心間 > 260px）で飛び道具を撃って牽制する（HARD のみ・クールダウン中はダッシュ接近にフォールスルー＝撃ちつ詰めつ）。AI はコマンド検出を経由しないため打撃必殺技（対空）は `startSpecial` 直呼びで済んだが、**飛び道具だけは弾の生成に Core 連携が要る**（`consumePendingProjectile()` を Core が読んで `spawnProjectile`）＝飛び道具が AI から撃てる唯一の特別扱い。データ駆動で、飛び道具を持たない純グラップラー（Iwao）の AI はこの反応をスキップしてダッシュで詰める
- **デバッグ**：当たり判定オーバーレイ（F1）・ヘッドレス自動スクショ
- **入力リプレイ（dev ツール・設計書タスク順の外）**：毎フレームの入力を記録（`-Dphantom.replay.record`）し、決定的シミュ（1 render=1 固定ステップ・dt 非依存・AI 乱数なし）で同じ試合を完全再現（`-Dphantom.replay.play`）。ゲーム状態の保存は不要＝入力列のみで成立。撮影モードと併用すれば再生中の任意フレームを PNG 化でき、連番化でリプレイ GIF も作れる。詳細は [docs/BattleSystem.md](docs/BattleSystem.md) の「入力リプレイ（記録 / 再生）」

動作証跡は [docs/screenshots/](docs/screenshots/) を参照（各タスクの静止画を収録）。

## 開発ワークフロー

```
「次のタスクを進めて」
  → next-task（ブランチ作成 → 実装 → ./gradlew build 緑 → 動作確認/スクショ → README 進捗更新）
  → kaizen-close（学びを CLAUDE.md / README / メモリへ反映）
  → self-review（push 前に自分の差分を別コンテキストでセルフレビュー = self-gate）
  → codex-pr（commit → push → gh pr create → @codex review → 自走レビューループ）
  → 3 系統レビュー（Codex / CodeRabbit / CI Claude）のクリーン後にユーザーがマージ
```

レビューは 3 系統で多重化する：**Codex GitHub App**・**CodeRabbit**・**CI 上の Claude（fresh context、`.github/workflows/claude-review.yml`）**。Claude のセルフレビューは「実装の経緯を持たない別セッションの Claude が PR の diff だけを見る」ことでバイアスを避ける。

詳細は [.claude/skills/](.claude/skills/) と [docs/workflow.md](docs/workflow.md)。
